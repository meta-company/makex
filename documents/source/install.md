# Installing Makex


## Using pip

Install Makex:

```shell

pip install makex
```

The Makex executable will be installed to `~/.local/bin/makex`.

Make sure `~/.local/bin` is on your `PATH`.

```{tip}
We recommend aliasing the makex executable to `mx` for brevity.
```
